# Conteúdo do Curso

## Materiais

### MOBILE_001.pdf
Resumo: Introdução ao JavaScript como base para desenvolvimento com React, abordando histórico, tipos de dados, variáveis, escopo, operadores e estruturas de controle.

### MOBILE_002.pdf
Resumo: Conteúdo sobre DOM, seleção e manipulação de elementos, eventos, programação assíncrona com callbacks, promessas e async/await.

### MOBILE_003.pdf
Resumo: Introdução a frameworks e bibliotecas, diferenças entre eles, conceitos básicos do React JS, componentes, JSX, Virtual DOM, hooks e criação de uma aplicação SPA com Vite.

### MOBILE_004.pdf
Resumo: Uso do React Hook useState para gerenciamento de estado, eventos onClick, geração de números aleatórios e implementação de rotas com react-router-dom.

### MOBILE_005.pdf
Resumo: Introdução ao Next.js, seus recursos principais como SSR, SSG, roteamento baseado em arquivos, deploy e hospedagem na Vercel.

### MOBILE_006.pdf
Resumo: Fundamentos de desenvolvimento mobile, comparando aplicações nativas, híbridas e cross-platform, além de introdução ao React Native e Expo com layout e estilização em Flexbox.

### MOBILE_007.pdf
Resumo: Desenvolvimento de um app mobile com navegação, integração de API simulada, detalhes de filmes, persistência local com AsyncStorage e estrutura de um case study com CineApp.

### MOBILE_008.pdf
Resumo: Implementação de um CRUD com Expo e Supabase, incluindo configuração do backend, navegação, reutilização de telas, uso de useFocusEffect, FAB e persistência na nuvem.

### MOBILE_009.pdf
Resumo: Desenvolvimento de um sistema de notificações em tempo real com Expo Notifications e Supabase Realtime, cobrindo arquitetura, banco de dados, políticas de segurança e fluxo de alertas para o usuário.
